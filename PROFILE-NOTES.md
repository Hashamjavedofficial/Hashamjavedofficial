# Profile maintenance

This README focuses on GitHub: an illustrated header, a short TypeScript introduction, an animated contribution snake, technology icons, account statistics, and public repositories. Employer/project case studies and the portfolio-style sales footer have been removed. The account avatar is a separate manual setting.

## Artwork

`python scripts/generate_profile_assets.py` rebuilds the six self-contained hero, typing, and navigation SVGs using Python's standard library. The supplied doodle is embedded unchanged. The hero has a phone variant, and local CSS animation respects reduced-motion preferences.

## Contribution snake and daily refresh

The snake is generated by [Platane/snk](https://github.com/Platane/snk), pinned to commit `d8f6715049803e982ee5ff501b6b9b7d5deeb09b` (v3.5.0). The username is explicitly `Hashamjavedofficial`. Its lavender snake consumes a mint contribution grid derived from that account, not the upstream author's example image. The initial SVG was generated with this pinned upstream bundle using the GitHub data snapshot in `assets/github-data.json`; local generation used no GitHub credential in the third-party code.

`.github/workflows/refresh-profile.yml` regenerates the cards and snake daily at 00:17 UTC (05:17 in Pakistan), on relevant script/workflow changes to `main`, or by manual dispatch. It uses the repository's ephemeral token, pinned checkout and snake actions, and a bot-authored commit. The action fetches the current contribution calendar from GitHub. It begins after the PR is merged. Failed refreshes preserve the last committed files and appear as failed workflow runs.

Visitors requesting reduced motion see the static GitHub calendar instead of the snake, with a separate narrow-screen version. Native GitHub links remain visible if an image fails.

## Data and external icons

`scripts/update_activity.py` queries GitHub's GraphQL API, saves dated aggregate data in `assets/github-data.json`, and produces the account cards and static calendars. Repositories and stars count owned public non-forks. Language counts describe repository contents, not proficiency. No private repository names or credentials are saved.

[Skill Icons](https://github.com/tandpfun/skill-icons) serves the three icon rows; each has alt text and a visible text equivalent. Shields.io serves three AI-focus badges. The public repositories are labelled as templates and experiments. Historical `build-loop.svg` and the standalone doodle remain available for reuse.
